# L3 雙評審盲測

詳見 `docs/wordbank-spec.md`。流程：

1. `python3 scripts/blind_review/build_papers.py <dir> [--ids 改到的id,...]` 產生考卷與答案。
2. 開兩個獨立評審（不同模型，例如 Opus 與 Sonnet），各自用 `reviewer_prompt.md` 作答每一份 `papers/*.jsonl`，
   結果寫到 `<dir>/results/<model>-<paper檔名>`。評審**不能**看到 `key/`。
3. 把 `grade.py` 複製到 `<dir>` 執行（`-v` 列出細節）：
   - FIX：任一評審把錯誤選項評為 1 以上 → 替換該選項，只重測改到的題目，最多 3 輪。
   - ESCALATE：評審質疑正解，或修 3 輪仍不過 → 交給人裁決。

## 評審本身要定期校正（金絲雀測試）

把已知有問題的舊題目和正常題目混在一起考評審。2026-10-10 校正結果：
第一版問法（選答案 + 列可接受選項）只抓到 27–53% 的壞題目；
現行的逐選項評分問法抓到 29/30（中）、30/30（英），正常題目誤報 5/30、2/30。
改動評審問法後，要重跑金絲雀測試確認抓錯率沒有下降。
